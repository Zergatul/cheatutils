Automatically switches to the best tool right before you start breaking block.
Selects tools according to the chosen priority. On equal speed, non-damageable items are preferred.
Enabled
Mode
Search for tools on hotbar
Search for tools in inventory
Priority
Prioritize Speed Prioritize Drop
Prioritize Speed: Chooses the fastest tool, accounting for the wrong-tool speed penalty. The block may break without dropping items.
Prioritize Drop: Prefers tools that meet the block's harvesting requirements, then chooses the fastest among them. If none qualify, uses the fastest available tool.
Harvesting requirements check tool type and tier. This option does not choose between Silk Touch and Fortune.
Hotbar Slot
When in inventory mode, module brings best tool to this slot on hotbar, and doesn't touch other slots.
Min Durability
Don't select tools which durability is less than specified value.
