Write a script to place blocks in range.
Every game tick the module runs your script for each replaceable block in range, such as air, water, or sea grass. The script receives the current block coordinates as x, y, and z parameters.
Inspect the block through game.blocks. When the script calls blockAutomation.useItem("block_id");, the module tries to place that block at the current position. The module places at most one block per tick.
