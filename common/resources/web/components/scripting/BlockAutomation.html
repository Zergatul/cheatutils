Write a script to place blocks in range.
Every game tick the module runs your script for each replaceable block in range, such as air, water, or sea grass. Read the current block through the currentBlock API.
When your script calls blockPlacer.setBlockId("block_id"); with a valid block ID, the module tries to place that block at the current position. The module places at most one block per tick.
