Allows you to connect CheatUtils to AI Agents.
Enabled
Allow Saving Scripts
Enables agent to be able to update and apply scripts live. Without this agent can only inspect compilation errors, read your scripts, compile its own scripts, but don't apply them or execute.
Allow Evaluating Expressions
Enables agent to evaluate arbitrary scripting expressions on the main thread. Expressions can mutate game or mod state and are not time-limited.
