Different Aim Assist hacks.
Bow Assist
Once you start using bow, module searches for the closest entity to your crosshair, and if it is possible to reach it with arrow and current bow power, then module sets its target as current entity. If you release bow you will rotate to the proper rotation on the server and shoot the arrow.
